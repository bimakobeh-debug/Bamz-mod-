# Bamz Mod — Demo Android Project

A standalone Android demo panel with a black/red gaming theme. This is a UI demo only:
- ESP Box / ESP Name / ESP Line toggles change demo status text.
- Aim Silent is a visual demo toggle only.
- It does not connect to, modify, inject into, or interact with Free Fire or any other game.

## Build
Open this folder in Android Studio, allow Gradle sync, then build the `app` debug APK.
This source project does not include a compiled APK because Android build tools are not available in this environment.

Requirements: Android Studio with a compatible Android SDK and Gradle installation.
